# Authentication Alignment

This directory is the local Markdown tracker and decision record for the frontend–backend authentication contract.

The current repository contains no implemented authentication flow, HTTP interface, token component, or frontend application. Its only authentication evidence is the intended `internal/auth` domain boundary. Consequently, this effort defines the first implementation contract rather than reconciling two existing implementations.

Start with the [Authentication Contract Alignment Map](./wayfinder-map.md). Its child tickets under [`tickets/`](./tickets/) are the only open decisions; each ticket records its own question, blockers, claim, and eventual resolution.
