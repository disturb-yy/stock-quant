# 03 — momentum_v1 唯一权威计算规格

此文档优先级高于示例代码。所有 Go 与 Python 必须实现相同定义，任何改变都需升级 `strategy_version`、因子版本及测试 fixture。

## 数据与样本
- 信号交易日期 T：中国 A 股交易日。每只股票取 `t-60 .. t` 共 61 个**市场交易日**数据，严格按日历映射，不可用 61 个“有成交的日期”替换。
- 原始 `Close` 元、`AdjFactor` 正实数、`AmountYuan` 元。前复权以 T 日为基准：`P_i = close_i * adj_i / adj_t`。永不使用 T 之后复权数据计算 T 的因子。
- 必须处理上市/退市日、停牌天数、缺日及官方事后数据修订；不允许静默前向填充停牌日价格。

## 四因子（固定）
- `momentum_60 = P[t]/P[t-60] - 1`，权重 40%，大优。
- `momentum_20 = P[t]/P[t-20] - 1`，权重 30%，大优。
- `amount_activity_20 = ln(avg(amount[t-19..t]) / avg(amount[t-39..t-20]))`，权重 20%，大优；分母必须 > 0。
- `volatility_20 = sqrt(252) * sample_std(log(P[i]/P[i-1]) for i=t-19..t)`，20 个收益观测，样本方差除以 19，权重 10%，**小优**。
- `MA20 = avg(P[t-19..t])`；近20日均成交额也使用 t-19..t。

## 先硬过滤（执行顺序固定）
- H1 SSE/SZSE 股票，排除 BSE（如果未来支持扩市场，升版本）。
- H2 交易日期在 `[list_date, delist_date)` 内（delist_date 语义需以实际交易状态校验；如退市当日不可交易，明确剔除）。上市距离 T 至少 120 **自然日**。
- H3 T 日 ST 状态可信且不是 ST/*ST；状态无法判断时 `strict` 阻断正式回测，非严格研究模式必须标 `ST_UNVERIFIED`。
- H4 T 日可交易且无停牌。可用 `suspend_d` / 交易记录交叉校验，单靠缺日不能推断停牌原因。
- H5 61 条按交易日完整且合法；价格、因子 > 0、金额 > 0（本版对完整窗口采用严格正数约束）。
- H6 20 日平均成交额 >= 30_000_000 元。
- H7 `P[t] > MA20`，等于也排除。
- H8 `momentum_60 > 0`，等于也排除。

## 标准化
只对**合格股票池**按每一个因子计算横截面 `[0,100]` 排名：坏到好排列，平均并列名次 r（从1开始），`N>1: 100*(r-1)/(N-1)`，`N=1:50`。波动率小值最优。因子值全部相同而 N>1 时各 50。

## 加权与结果
`score = .40*S_M60+.30*S_M20+.20*S_ACTIVITY+.10*S_LOWVOL`。不得再对 100 分做归一化。按 score desc、原始 M60 desc、TS code asc 取 Top 20。保留全量合格集、Top N、过滤原因，不提前 round，展示四舍五入两位。

## 边界与状态
0 合格票 -> 成功但 empty result（如基础数据完备）；基础数据不完整 -> `DATA_INCOMPLETE` 失败且不发布排名；未知 ST 在严格模式 -> `DATA_UNTRUSTED` 不能正式评分/回测；NaN/Inf -> 校验失败；数据更新时间在 T 日当日盘后但早于 signal 时不可用于 T+1 的假设交易。

## 过滤样例和反例
- `AvgAmount20=30_000_000` => 通过；`29_999_999` => 排除。
- `CloseAdj=MA20` => 排除；`Momentum60=0` => 排除。
- 因子同值平均排序；N=1 得分四项均 50 -> 总分 50。
- 合格池甲乙丙 M60 `[1,2,3]` -> `[0,50,100]`；LowVol 原值 `[.1,.2,.3]` -> `[100,50,0]`。
