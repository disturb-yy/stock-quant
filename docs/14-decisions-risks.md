# 14 — ADR 决策记录与风险清单

## 已冻结
- ADR-001：Go 模块化单体，不使用微服务/消息队列（初版）。
- ADR-002：Python subprocess 是 v1 Python Runner，先计算因子，不直接评分或访问 Tushare。
- ADR-003：Tushare 的原始行情保留未复权并单独存复权因子，按 signal T 日计算前复权。
- ADR-004：动量 40/30、成交额活跃度 20、低波动 10；窗口 60/20/20/20；样本 STD 和 252 年化；严格61交易日。
- ADR-005：先硬过滤再横截面百分位（平均并列）；总分 0～100；确定性排序。
- ADR-006：严格 ST 历史状态不可信 -> 不能产出正式回测；可提供另行标记的探索研究，但必须显著披露。
- ADR-007：交易 T 日信号、T+1 可能成交；未实施企业行为现金/持股处理时回测只能 research-only。
- ADR-008：所有交接通过文件、测试证据、不可变快照标识，不通过 AI 会话私有上下文。
- ADR-009：市场原始行情和复权因子使用精确十进制值，并以十进制文本绑定 MySQL `DECIMAL`；需要数值计算时只在计算边界显式转换为 float64。`DECIMAL(24,4)` 可保存 `9007199254740993.0000`，但 float64 会将其舍入为 `9007199254740992.0000`，因此禁止浮点持久化和浮点 revision 比较。

## 风险及规避
| 风险 | 影响 | 规避与阻断 |
|---|---|---|
| 2000 积分缺历史 ST 官方权威源 | 历史回测偏差 | strict BLOCKED；探索显著标记 |
| Tushare 事后修订原始行情/因子 | 历史重跑不同 | 记录原始 hash/revision，保留不可变快照引用 |
| 以 61 个股票交易日代替 61 市场交易日 | 停牌序列误算 | 依据交易日历强校验 |
| 多语言因子结果不一致 | 排名偏差 | Go/Python 双实现同 fixture 测试、容差 |
| Python 超时/输出失控 | Go 阻塞/内存耗尽 | 进程组 kill、限制最大输出/并发 |
| 历史股票只取 L | 幸存者偏差 | L/D/P 全状态和退市日期 |
| 上市日数据不足 | 无效因子 | 严格缺窗剔除 |
| 开盘涨停仍乐观买入 | 回测收益虚增 | 无法成交拒单、输出理由 |
| 日频数据提前使用未落库指标 | 未来数据或失败 | sync quality gate, 版本化 snapshot |

## 待 P00/P10 冻结的默认项
- Go 正式版本、MySQL/Node/Python 具体小版本；默认建议统一开发机和 CI 锁定。
- 回测初始资金、佣金最低费用、滑点与税费；这些都是**假设参数**，不得假装真实成本。
- 企业行为现金股息/送转支持范围；未支持则研究标签。
