## 实现摘要

- 在 Tushare 客户端接入进程内 global/per-api 限流。默认全局 100 次/分钟、普通 API 100 次/分钟、`stock_basic` 40 次/分钟，速率可配置，突发容量为 1；取消限流等待不消耗配额。
- 对 HTTP 429、5xx 和明确瞬时网络错误有限重试；默认最多 3 次尝试（含首次请求），指数退避使用 full jitter，默认基数 100ms、上限 2s。每次 HTTP 尝试都重新经过双重限流；限流、退避和 HTTP 共用调用方 context 与默认 30 秒总期限。
- 不重试权限 2002、其他 provider 业务拒绝、参数错误、响应结构/解析错误以及取消/超时。重试判定使用私有可恢复标记，不单凭 `UPSTREAM_UNAVAILABLE` 领域码。
- 每次查询结束写安全结构化 `slog` 日志，默认 `slog.Default()` 并支持注入 logger。日志只含本地 request ID、API、总时延、行数、白名单业务日期、错误分类和尝试次数；不写错误原文、Token、请求体、任意参数或 provider 原始消息。另提供 `Observer` 指标适配 hook；指标标签不得使用 request ID 或业务日期。
- 增加 fake clock、并发、速率阈值、取消时隙恢复、重试边界、日志脱敏和瞬时网络错误测试；同步 Tushare 契约及包级规约/导航。
