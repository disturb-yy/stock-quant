## 实现摘要
- 两份现有 JSON Schema 是唯一 wire contract。请求与响应的 `as_of` 加入 Draft 2020-12 `format: date` 断言，并限定公历年份 `0001`–`9999` 以统一 Go/Python 行为；schema 保留必填字段、封闭对象、hash、枚举和结果错误数组约束。
- 新增 Go 包级 DTO 和 `DecodeRequest`/`DecodeResult`、`EncodeRequest`/`EncodeResult`。schema 通过 `go:embed` 固定在二进制内；校验 Draft 2020-12、日期格式、未知字段和恰好一份 JSON 文档。
- 新增 Python `stockquant.protocol` 对应 dataclass 与编解码器。它读取同一份契约文件；schema 缺失或编译失败时拒绝继续。拒绝多文档、非标准常量、无效日期、额外属性和超出有限浮点范围的 JSON 数值；所有 JSON 整数按 Go `float64` 语义解析，避免跨语言 DTO 精度不一致。
- 明确 v1 wire 兼容规则：改变接受/拒绝语义或字段含义（含增加可选字段）必须新建版本 schema；版本必须显式声明；禁止推断版本或填入必需默认值；升级适配留在协议边界。
- 增加 Go `jsonschema/v6` 和 Python `jsonschema[format]` 依赖；Python 直接及传递依赖均固定版本，Make/CI 安装锁定清单；同步 `contracts/AGENTS.md`、`contracts/INDEX.md`、根 `INDEX.md` 和环境设置文档。
- 未变更业务计算、API、数据库或数据源行为。
