## 实现摘要

- 为 `stock_basic`、`trade_cal`、`daily`、`adj_factor`、`suspend_d`、`stk_limit` 建立 DTO、字段解码与映射逻辑，并添加对应的 source-schema fixtures。字段按 API 列名读取，允许 provider 列顺序变化和未知扩展列；按必选性校验缺失、空值、null、日期和数值。
- `daily.amount` 以精确十进制从千元乘 1000 转为元；`vol` 保持“手”。停牌与涨跌停接口保留 provider DTO，不推导领域事件或新增数据库表。
- 增加纯值类型 `types.Decimal`，市场日线价格、成交量、成交额及复权因子不经 float64 传递。需要计算时可显式调用 checked float64 转换。
- MySQL 使用参数化十进制文本写入，读取时以 `CAST(... AS CHAR)` 取得 DECIMAL 文本并精确解析；字段变化/revision 判断继续由 MySQL DECIMAL 精确比较，不经过浮点。
- 新增 ADR-009 记录精度决策，并同步 Tushare/数据库文档、领域/类型边界、包级 `AGENTS.md`/`INDEX.md` 与根索引。
