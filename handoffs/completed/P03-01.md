## 实现摘要

- 新增 `internal/infrastructure/tushare.Client`，以受控 endpoint 发送 JSON POST，请求包含 `api_name`、`token`、`params`、`fields`；默认 HTTPS，明文 HTTP 只允许 loopback 测试地址，并关闭重定向跟随。
- 按响应 `data.fields` 与 `data.items` 的列顺序动态构建行，保留未知字段和 `json.RawMessage` 原值；支持空 `items`，拒绝缺少响应成员、重复/空字段名、缺必需字段和行列宽度不符。
- 每次请求沿用调用方 context 并设置默认 30 秒有界超时；错误映射至既有领域码，覆盖 provider code 2002、HTTP 429、超时、取消、上游不可用和响应不完整。错误上下文不包含 Token 或请求体。
- 增加 httptest fixtures 和错误/安全/资源失败用例；更新 Tushare 契约、包级 `AGENTS.md`/`INDEX.md` 与根索引。
